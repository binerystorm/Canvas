# Description
This is drawing program written in python. It is worth noting that this project was written, not to be a functional/useful drawing program, but rather to explore certain features of python as well as learn how a drawing program is implemented.

# Dependencies
This project depends on PyGame. Install PyGame with:
```
$ pip install pygame
```

# Usage
To run the program, execute following within the project directory:
```
$ python main.py
```
